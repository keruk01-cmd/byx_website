# ABOUT 발광·줄 단위 등장·이동 메뉴

후속 회전 범위·국소 밀도·유리 전환·푸터 수정은 [최신 구현·검증](INTERACTION_POLISH_2026-11-05.md)을 우선합니다. 아래 방향키/Escape·690ms 메뉴 기록은 이전 상태입니다.

2026-11-05 추가 사용자 요청의 구현·검증 기록입니다. [이전 기록](ABOUT_DEPTH_2026-11-05.md#사각-파티클과-국소-상호작용)의 단어별 등장·3,888개 면·경험 고정 선 기준을 갱신합니다.

## 현재 동작

- ABOUT 문구는 화면에 실제로 배치된 **한 줄씩** 같은 투명도로 등장합니다. 자연/명시적 줄바꿈을 유지하고 화면 폭/폰트 로딩이 바뀌면 줄을 다시 측정합니다. 한번 드러난 밝기는 줄 재배치나 역스크롤에도 낮아지지 않습니다. 제목 알파벳 변환과 세 장면의 누적 진행은 보존합니다.
- 경험은 상시 회색 웹과 원형 그라디언트를 제거했습니다. **96개 이동 선**이 양방향으로 원점을 통과하는 대각선 X 궤적과 긴 잔상을 그립니다. 선 자체를 별도 버퍼에 그린 뒤 넓은 블러/좁은 블러/선명한 중심을 가산 합성해 발광을 표현합니다. 커서 가까운 선의 밝기·두께·속도 반응은 유지합니다.
- 은하는 **5,832개 입체 사각 면**으로 늘렸습니다. **3,402개는 중심부**, 나머지는 나선 팔을 채웁니다. 각 면의 투명도는 서로 다른 주기와 결정적 시드의 부드러운 노이즈로 계속 바뀝니다. 배경 원반/리본/이미지 없이 면만 사용하며 깊이·기울기·미세 이동과 클릭/드래그/키보드 회전을 유지합니다.
- 은하 클릭 시 Canvas 외곽의 흰 포커스 사각형은 표시하지 않습니다. 키보드 포커스에는 작은 회전 키 안내를 표시합니다. 방향키/Enter/Space/Escape와 터치의 네이티브 스크롤은 유지합니다.
- 데스크톱 메뉴는 **하나의 공유 캡슐**이 기존 메뉴에서 새 메뉴로 약 690ms 동안 이동합니다. 이동 중 폭이 늘고 높이가 줄었다가 살짝 지나친 뒤 알약으로 복원됩니다. 반투명 유리·광택과 가속/감속을 적용하며 빠른 연속 선택도 현재 위치에서 이어갑니다. 밝은/어두운 헤더의 문자 대비·키보드 선택·크기 변경·모바일 메뉴 복귀를 처리합니다.
- 모션 감소에서는 문구를 모두 표시하고 장면을 정지하며 메뉴 캡슐은 즉시 정착합니다. 화면 이탈/모달/문서 숨김에서 장면 렌더링을 멈추고 ABOUT 이탈 시 발광 버퍼와 이벤트를 정리합니다.
