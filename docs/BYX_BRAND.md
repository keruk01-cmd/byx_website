# BYX 브랜드 기준

작성일: 2026-10-25. 최종 정리일: 2026-11-03. 상태: 초기 개발 기준 수립 완료 / 후속 사이트 개선 로컬 구현·데모 검증 완료 / 운영 미배포. 현재 구현·실행 방법·검증 범위와 남은 항목은 [작업 정리](SITE_UPDATES_2026-11-03.md)를 따릅니다. 아래 초기 검토·미결 목록은 전체 브랜드 사양의 확정을 뜻하지 않습니다.

관련 문서: [AGENTS.md](../AGENTS.md), [PROJECT.md](../PROJECT.md), [CLAUDE.md](../CLAUDE.md), [CHANGELOG.md](../CHANGELOG.md), [구현 계획](BRAND_IMPLEMENTATION_PLAN.md).

후속 사용자 결정(2026-11-03): 영문 디스플레이는 기존 **Anton을 유지**하고, 사이트를 새로 구성하기보다 기존 화면·기능을 점진적으로 개선합니다. 아래 초기 정방형 서체 탐색 방향은 이 결정으로 보류합니다. ABOUT은 Variable X와 eXperience X를 하나의 회전·형태 전환·포인터 반응 X 점군으로 표현하며, 이전 이미지 프레임과 건물 스터디는 제거했습니다. 점군 영역의 검은 배경은 화면 양 끝까지 확장하고 두 이름을 그 위에 흰 글자로 표시합니다. 형상 이름 캡션은 제거하며 클릭·호버 분산을 강조합니다. 공통 헤더에는 뿌연 유리 표현을 적용하고 슬롯머신 로고는 유지합니다. 일시정지 버튼 없이 모션 감소·화면 밖/숨은 탭 정지를 제공합니다. 현재 구현 값이 전체 매체의 최종 브랜드 사양 확정을 뜻하지 않습니다.

## 1. 상태의 의미

- **확정사항**: 사용자가 이번 작업에서 지정한 방향과 보존 조건입니다. 실제 화면 적용 완료를 뜻하지 않습니다.
- **검토사항**: 방향을 구현하기 위해 비교·시험할 제안입니다. 확정된 사양이 아닙니다.
- **미결사항**: 아직 선택하지 않은 형태·값·범위입니다. 임의로 최종값을 정하지 않습니다.

## 2. 확정사항

| 항목 | 기준 | 현재 적용 상태 |
|---|---|---|
| 주체 | ARCHITECTS BY X(BYX) 공식 웹사이트 | 기존 BYX 사이트 운영 구조 유지 |
| 공통 구조 | X를 모든 핵심 그래픽 시스템의 공통 구조로 사용 | ABOUT의 단일 X 점군에 로컬 적용, 전체 매체 규칙은 미확정 |
| Variable X | X의 형태·두께·비율이 변화하는 가변 그래픽 | ABOUT에서 크기·비율이 다른 X와 네 입체 형상 전환 구현. 전체 브랜드 수치는 미정 |
| eXperience X | X를 이미지 프레임과 인터랙션에 활용 | 후속 결정으로 ABOUT은 이미지 프레임을 제거하고 점군의 호버·클릭 분산/복귀로 표현 |
| 영문 디스플레이 방향 | 사용자 후속 결정에 따라 Anton 유지 | Gasoek One·Archivo Black 교체 실험 보류 |
| 본문 방향 | Wanted Sans | 현행 SUIT Variable 유지, 미적용 |
| 레퍼런스 | Athletics의 XR 브랜드 아이덴티티를 핵심 참고로 사용, 직접 복제 금지 | 원리 검토 단계 |
| 색상 | 별도 결정 전까지 기존 흑백 체계 유지 | 네 가지 UI 토큰과 본문 색상 예외 보존 |
| 슬롯머신 로고 | 사무소의 중요한 정체성으로 존중, 보존을 기본으로 검토 | 교체·삭제 계획 없음 |
| 기술 | 단일 HTML, Supabase CMS, Vercel 배포와 기존 기능 유지 | 실행 파일의 로컬 개선, 기존 연동·배포 구조 보존. 운영 변경 없음 |

X의 공통 구조는 핵심 그래픽 간 관계를 만드는 원칙입니다. 모든 버튼·문자·사진을 X로 바꾸는 요구로 해석하지 않습니다. 작품의 이해와 읽기·탐색 기능을 우선합니다.

## 3. 기존 정체성과의 관계

현재 제목·로고·메뉴는 Anton 중심이고 본문·라벨은 SUIT Variable 중심입니다. CSS 변수로 색상·여백·서체를 공유하며, `clamp()` 타이포그래피와 1px 그리드가 정보 밀도를 조절합니다. 사진 없는 항목은 `svgArt()`가 채웁니다.

슬롯머신의 빈칸과 여러 분야의 단어는 BY X 앞에 다양한 작업 영역이 들어오는 기존 개념입니다. 새 X 그래픽은 우선 이 개념과 공존하는 확장 시스템으로 검토합니다. 공존이 어려운 경우에도 로고 변경을 자동 결론으로 삼지 않고, 그래픽의 위치·크기·모션 우선순위를 먼저 조정합니다.

현행 `--font-display`는 슬롯·메뉴·제목에 함께 쓰입니다. 후속 서체 시험에서는 슬롯의 상속 관계와 문자 폭을 분리 검토해야 합니다. 본문 변경도 `--font-text`뿐 아니라 `.mono`, `.art`, 폼, 한글 제목 폴백을 함께 확인해야 합니다. 현재 한글 `wght` 보정값을 새 폰트의 확정값으로 옮기지 않습니다.

## 4. 검토사항 — BYX 고유 규칙을 만들기 위한 제안

### Variable X

- 중심 교차점과 두 대각 방향을 공통 골격 후보로 비교합니다. 최종 윤곽은 미정입니다.
- 두께, 가로·세로 비율, 팔의 벌어짐, 교차부 면적을 변화 축 후보로 비교합니다.
- 정적 기본형과 제한된 변형 세트를 먼저 검토하고, 이후 인터랙션에 연결합니다.
- 작은 크기에서도 X로 읽히는지, 곱셈·닫기 아이콘과 혼동되지 않는지 확인합니다.
- 장식 X는 실제 닫기 버튼 역할을 하지 않으며, 보조기술에는 불필요한 반복 정보를 전달하지 않도록 계획합니다.

### eXperience X

- 후보: 이미지 바깥 프레임, 부분 오버레이, 여백에서 이어지는 X, 제한적 마스크.
- 건축 사진의 전체 구도·공간·도면 판독을 가리지 않는 방식을 우선 비교합니다. 원본 파일은 가공하거나 덮어쓰지 않습니다.
- 썸네일에서 프레임을 써도 상세 이미지 전체 보기와 기존 갤러리 조작은 유지합니다.
- hover, 키보드 focus, 터치의 정적·선택 상태를 함께 설계합니다. 핵심 정보는 hover나 모션에만 의존하지 않습니다.
- `prefers-reduced-motion`에서는 의미가 같은 정적 상태 또는 즉시 전환을 제공합니다. 슬롯과 새 그래픽의 동시 움직임은 시각적 경쟁을 점검합니다.

### 타이포그래피

- Wanted Sans는 본문 방향으로 확정하되 버전·파일·굵기·행간·자간·폴백·포함 글리프는 시험 후 정합니다.
- 디스플레이 후보는 정방형 인상, 두꺼운 획, 영문 X/B/Y 형태, 숫자, 긴 제목·메뉴 폭, 한영 혼용을 같은 문구로 비교합니다.
- Gasoek One은 인상 기준이며 채택 확정이 아닙니다. 후보 목록과 최종 선택은 후속 비교 결과로 기록합니다.
- 웹폰트 출처·배포/임베딩 조건·고지 방식과 파일 용량을 확인합니다. 기존 내장 방식 안에서 적용 가능성을 먼저 검토하고 폰트 CDN이나 빌드 도구를 추가하지 않습니다.
- 로고 서체와 본문·제목 서체를 동일하게 교체해야 한다고 가정하지 않습니다.
- 현행 Anton은 폭이 좁은 서체이므로 정방형 인상의 후보로 바꾸면 같은 크기에서도 메뉴·카드·표의 글자 폭이 달라집니다. 제목 크기만 바꾸는 방식으로 결정하지 않고 줄바꿈·정보 밀도·슬롯의 고정 BY X 위치를 함께 비교합니다.

|---|---|---|

| X-02 | 두께·비율의 최소/최대와 변형 조합 | 정적 변형표, 작은 크기 판독 결과 |

색상은 이번 미결 목록을 이유로 자동 확대하지 않습니다. 별도 결정 전까지 현재 토큰을 유지합니다. 위 표의 결과가 나오면 선택 내용·근거·날짜를 이 문서에 기록하고 구현 계획을 갱신합니다.

## 6. 레퍼런스와 출처

- [Athletics — XR 공식 사례](https://athleticsnyc.com/work/xr): 공식 설명에서 X의 획 변화, 생성 패턴, 확대 글자 형태의 프레임 활용을 확인했습니다. BYX에는 가변성·일관된 구조·프레임 활용이라는 원리만 참고합니다. XR의 윤곽, 둥근 끝단, 색상, 이미지, 패턴, 애니메이션 값을 가져오지 않습니다.
- [Wanted Sans 공식 저장소](https://github.com/wanteddev/wanted-sans): 폰트 파일·버전·사용 조건을 확인할 원본 출처입니다. 이번에는 폰트를 다운로드하거나 내장하지 않았습니다.

공식 페이지 재확인일: 2026-11-03. XR 사례는 텍스트 설명을 확인했으며 동영상의 시간·이징·기하 수치를 측정하지 않았습니다. Wanted Sans는 공식 저장소를 확인했으며 적용할 파일·버전과 고지 방식의 최종 검토는 후속 작업입니다.

| 공식 사례에서 확인한 내용 | BYX에서 검토할 원리 | 가져오지 않는 요소 |
|---|---|---|
| XR의 X 획이 가늘어지고 두꺼워지는 모션 | 공통 X 구조에서 제한된 변형을 만드는 방식 | 로고 윤곽·곡률·모션 값 |
| 문자 형태로 구성한 생성 패턴 | 여러 매체에 일관된 그래픽 규칙을 적용하는 방식 | XR 패턴·전용 생성 도구 |
| 확대된 X를 프레임으로 활용 | 건축 사진·도면을 읽을 수 있는 프레임 비교 | XR 이미지·크롭·배치 |

레퍼런스 설명과 BYX용 제안은 구분합니다. 위 검토사항은 XR의 사양을 전사한 것이 아니라 BYX 적용을 위한 제안입니다. Variable X와 eXperience X의 방향은 이번 사용자 지시이며, 표의 비교를 근거로 구체적 형태가 확정되지는 않습니다.
