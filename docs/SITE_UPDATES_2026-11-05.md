# FEED 통합 · 구성원 카드 편집 · ABOUT 스크롤 여정

2026-11-05 사용자 후속 요청. 공개 화면과 관리 화면의 실행 코드는 단일 `index.html`에 유지합니다.

## 구현

- FEED의 새 소식/새 글 버튼을 **새글** 하나로 통합했습니다. New Post의 Category에 `NEWS`를 제안하며, 같은 본문 편집기에서 소식을 작성합니다. 관리자 Feed 목록은 기존 news와 posts를 날짜순으로 함께 표시하고, 각 항목은 원래 표에서 수정·삭제합니다. 기존 데이터 이전·표 병합·주소 변경은 없습니다.
- ABOUT 편집은 구성원 카드만 표시합니다. 카드에서 사진·이름·직책·학력/이력·소개를 함께 편집하고 추가·제거합니다. 학력/이력은 한 줄에 하나씩 입력합니다. 순서 손잡이는 마우스/터치 드래그와 키보드 방향키를 지원하며, 사진과 전체 정보가 한 묶음으로 이동합니다. 입력 중에는 다시 렌더하지 않습니다.
- 저장 형식은 기존 `이름 | 직책 | 이력 | 사진주소 | 소개`입니다. 기존 4칸·선택적 5칸·추가 칸을 보존하며 사진은 기존 압축/업로드 경로를 사용합니다. 비동기 업로드 중 편집 카드가 변경되면 다른 구성원에게 사진을 붙이지 않습니다. 카드 제거는 설정 저장 때 반영하고 Storage 원본을 지우지 않습니다.
- ABOUT 내부 문구 편집 필드를 제거하고 소스의 `ABOUT_STORY`를 공개 기준으로 사용합니다. 기존 story/Studio/Facts/Records 설정은 저장 객체에 보존하지만 공개 문구를 덮어쓰지 않습니다. 첫 화면의 `ARCHITECTS BY X`를 삭제하고 `POSSIBILITIES BY X`와 문장이 아닌 제목의 마침표를 제거했습니다. 완결된 한국어 문장의 마침표는 유지합니다.
- 제목은 약 3.4초 동안 여러 알파벳으로 바뀐 뒤 차례로 고정됩니다. 고정된 각 글자 칸에 대체 글자를 맞춰 겹침을 방지하며, 스크린리더에는 최종 제목을 처음부터 제공합니다.
- 경험 장면: 검은 전체 배경에서 탐험하는 점과 긴 궤적이 스크롤에 따라 중앙의 네 잎 곡선 형태로 모입니다.
- 기술 장면: 위에서 아래로 떨어지는 데이터가 BYX 알고리즘에 모이고, 이를 지난 입자가 큰 입체 궤도·곡선·점 구조로 완성됩니다. 별처럼 흩어진 점과 여러 겹의 선으로 공간감을 표현합니다. 실제 데이터 처리 결과를 표시하는 장면은 아닙니다.
- 두 장면은 모바일에서도 본문의 뒤에 고정되는 배경입니다. 이번 사용자 지시에 따라 이전의 작은 비고정 그림을 갱신했습니다. 본문은 계속 자연스럽게 스크롤하고, 마지막 구간에는 중앙의 결과물만 남습니다. 역스크롤 시 장면도 되돌아갑니다. 모션 감소에서는 완성된 정지 그림과 짧은 일반 본문 흐름을 제공합니다. 숨은 탭·화면 밖·모달에서는 프레임을 멈추고 라우트 이탈 시 정리합니다.
