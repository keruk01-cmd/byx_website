# ABOUT 표현·모바일 흐름과 WORKS 필터

2026-11-04 사용자 후속 요청에 따른 변경입니다. 이전 스크롤 소개 기록보다 이 문서가 현재 화면의 기준입니다.

## 변경

- ABOUT은 Variable X와 eXperience를 연결하는 시스템, 과정 전체의 경험, 생각과 기술의 연결이라는 3개 챕터를 유지합니다. 긴 사례/조건 설명을 빼고 각 챕터 소개는 한 문장, 과정/기술은 각 2개의 짧은 설명으로 압축했습니다. 건축·대지·법령·도면 등 특정 서비스에 한정된 표현은 공개 소개 본문에서 제거했습니다. 상호·로고와 실제 구성원의 직책/이력은 보존했습니다.
- 수식 행과 반복된 마무리 약속은 공개에서 제거했습니다. 기존 `settings.about`의 키/데이터는 지우지 않으며 기존 약속 문구는 관리 화면에서 보관 항목으로 표시합니다. 운영의 ABOUT 설정에는 `story_*` 사용자 저장 값이 없어 새 기본 문구가 적용됩니다. 운영 데이터는 수정하지 않았습니다.
- 제목의 대체 글자가 좁은 글자 칸 밖으로 넘던 문제를 수정했습니다. 비슷한 폭의 알파벳을 선택하고 각 칸 안으로 폭을 제한합니다. 글자는 한 겹이며 스크린리더에는 최종 제목을 제공합니다. 모션 감소에서는 즉시 최종 제목입니다.
- 과정은 선들이 만나 X를 이루는 곡선 그래픽, 기술은 기하학 데이터→입체 BYX→연결된 형태로 교체했습니다. Canvas/기존 서체만 사용하고 라이브러리는 추가하지 않았습니다. 화면 밖·숨은 탭·모달에서 프레임을 멈추고 라우트 이탈 시 정리합니다. 실제 연산 결과를 보여주는 그래픽은 아닙니다.
- 모바일(760px 이하)의 과정/기술 그래픽은 일반 흐름으로 본문과 함께 스크롤합니다. 화면 위에 남아 아래 텍스트를 가리지 않으며 설명의 강제 최소 높이를 제거했습니다. X 양옆 문구는 데스크톱과 동일하게 수직 중앙을 사용합니다. 기존 X 결집 구간은 유지합니다.
- People은 약 18px/s로 우→좌 순환하고 멈춤 버튼을 제거했습니다. 모달의 0.4초 등장과 배경 전환을 추가했습니다. 포인터/터치 선택 후 닫을 때 반환된 포커스가 자동 이동을 계속 막던 상태를 해제합니다. 키보드로 탐색 중인 카드의 정지·모달 닫은 뒤 포커스 복귀는 보존합니다. 모션 감소는 정적 가로 목록, 1명은 정적 카드, 0명은 섹션 생략입니다.
- People부터 문의/푸터까지 검은 배경을 연결했습니다. 모달과 입력은 밝은 배경을 유지합니다. 푸터 표기는 `© 2026 ARCHITECTS BYX. ALL RIGHTS RESERVED.`이며 내부 구분선을 제거했습니다. 넓은 화면은 한 줄, 좁은 화면은 사업자 정보를 다음 줄로 배치하고 여백을 줄였습니다. 상호·대표자·사업자번호·인스타그램 링크를 보존했습니다. 모바일 메뉴에서 예전 주소·연락처는 삭제했습니다.
- WORKS 보기 전환을 왼쪽으로 옮기고 오른쪽에 필터 아이콘을 추가했습니다. 모달은 실제 등록된 프로젝트의 유형·상태·연도를 선택하며 AND 조건으로 적용합니다. 적용 개수를 표시하고 초기화/닫기/Esc/바깥 클릭/Tab 탐색을 지원합니다. 취소는 필터를 바꾸지 않고 재개방 시 적용된 값으로 복원합니다. GRID/INDEX·기존 정렬·무한 로딩은 필터 결과를 공유하며 일치 결과가 없으면 안내합니다. 페이지 이동 중 모달이 열려 있어도 본문 스크롤 잠금을 복원합니다.
