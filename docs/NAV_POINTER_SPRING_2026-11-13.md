## 동작

- 메뉴 항목의 중심점으로 확장량을 정하던 방식을 제거했습니다. 메뉴 전체 영역에서 마우스의 실제 X 좌표와 현재 선택 캡슐 중심의 차이를 연속값으로 계산합니다. 같은 메뉴 안과 항목 사이 빈 공간도 반응합니다. 최대 범위는 14px로 부드럽게 제한합니다.
- 포인터 이벤트는 목표 좌표만 바꿉니다. 하나의 감쇠 스프링이 기존 위치·속도를 보존하며 새 목표를 따라가므로 빠른 이동·방향 전환·메뉴 이탈에서도 애니메이션을 매번 다시 시작하지 않습니다. 이탈하면 같은 스프링으로 원래 형상에 복귀합니다.
- 캡슐의 반대쪽 끝·높이는 유지하고 해당 방향 끝만 확장합니다. 반전 글자는 역스케일해 고정하며 헤더 굴절 구멍도 같은 형상을 따릅니다. 글자 DOM/렌즈 맵은 포인터 이동 중 다시 만들지 않습니다. 정지하면 프레임을 멈춥니다.
- 클릭 전환은 기존 320ms 이동과 얇아졌다 복구되는 동작을 사용합니다. 현재 보이는 형상에서 출발하고 도착 후 최신 포인터 좌표를 이어받습니다. 호버로 라우트나 `aria-current`를 바꾸지 않습니다.
- 마우스/정밀 호버에서만 활성화합니다. 키보드는 복귀하고 터치·모션 감소·숨은 탭·리사이즈/모바일 전환은 이동을 종료하고 기본 형상을 복원합니다.
- 프로젝트의 일반 스크롤·하단 반사 겹침과 CMS·설정·원본 이미지·서버·DB·Vercel은 보존합니다. 단일 HTML과 기존 런타임 의존성을 유지합니다.
