## 화면과 동작

- [Arc Liquid tab bar](https://uiarc.dev/components/liquid-tab-bar)의 마우스 호버 방향 반응과 모션 감소 원칙을 참고했습니다. Pro 소스·React/Motion 패키지는 사용하지 않았습니다. 현재 사이트 링크 구조와 글자만 있는 메뉴를 보존합니다.
- 선택 캡슐은 호버한 다른 메뉴 쪽 끝만 최대 10px 확장하고 반대쪽 끝·높이를 유지합니다. 240ms의 부드러운 복귀/확장을 사용하며 반전 글자와 헤더 굴절 구멍도 같은 형상을 따릅니다. 메뉴 글자 자체는 이동하거나 늘어나지 않습니다.
- 호버로 라우트나 `aria-current`를 바꾸지 않습니다. 기존 320ms 메뉴 클릭 이동·얇아졌다 복구되는 동작은 보존합니다. 이동 중 호버는 도착 후 반영하고, 빠른 호버 변경/복귀는 현재 화면 형상에서 이어갑니다.
- 마우스와 정밀 호버 환경에서만 반응합니다. 터치 입력·키보드 조작·모션 감소·모바일 전환·숨은 탭에서는 호버 확장을 지웁니다. 모바일 메뉴는 그대로입니다.
- 프로젝트 상세를 `project-scene`으로 감싸고 그 안에서 Cover Flow가 스크롤 중 뒤에 머물도록 했습니다. 본문·코드/스펙의 배경은 투명하고 행 구분선은 없습니다. 별도의 흰 패널 없이 글이 이미지 위로 지나갑니다.
- 글이 겹치는 정도에 따라 전체 그림을 최대 16%까지 옅게 하고 글 주위에 작은 밝은 그림자를 둡니다. 초기 사진 탐색 구간의 밝기와 드래그·던지기·트랙패드·방향키 조작은 보존합니다. 원본 사진은 계속 `contain`이며 캡션/저장/추가 정보 UI는 없습니다.
- 모션 감소에서는 배경 고정을 제거하고 일반 문서 흐름과 전체 밝기를 사용합니다. 스크롤 프레임·리스너는 라우트 이탈 때 정리합니다.
