# ABOUT · 검은 여백·곡면 은하·긴 잔상·확대

2026-11-05 후속 요청. 현재 간격·밀도·커서 반응·완성 크기는 이 기록이 [앞선 도시→은하 구현](SITE_UPDATES_2026-11-05.md)보다 우선합니다.

가장 최신 제목 전환·사각 은하·클릭 회전·경험 조명/속도는 [사각 파티클과 국소 상호작용](#사각-파티클과-국소-상호작용)을 우선합니다. 아래 곡면 은하 기록은 이전 구현입니다.

후속 요청에 따라 문구와 세 애니메이션의 스크롤 진행은 [스크롤 등장과 진행 유지](#스크롤-등장과-진행-유지)를 우선합니다. 같은 ABOUT 방문에서는 역스크롤로 상태를 되돌리지 않습니다.

## 변경

- 첫 X→경험, 경험→기술 사이에 각각 `100svh`의 검은 간격을 둡니다. 앞 장면과 다음 장면이 모두 화면 밖으로 빠진 빈 검은 구간이 생깁니다. 모션 감소에서는 간격을 64~120px 범위로 줄여 긴 빈 스크롤을 피합니다.
- 경험 장면은 이동 포인트의 짧은 점 꼬리를 제거했습니다. 각 이동체는 약 0.95rad 길이의 연속 곡선 잔상이며, 꼬리에서 앞부분으로 밝아지는 10개 구간으로 표현합니다. 기존 약 0.126rad 꼬리보다 7배 이상 길고, 원점을 지나는 X 웹과 양방향 움직임을 유지합니다.
- 경험 형상은 완성 시 1.5배 확대를 목표로 합니다. 화면 높이/폭이 부족하면 전체 형상이 잘리지 않도록 확대율을 제한합니다. 특히 모바일에서는 기존보다 크게 보이면서 네 잎 전체를 유지합니다.
- 도시의 81개 건물과 차량 흐름은 유지합니다. 전환 후 은하는 기존 324개 조각에서 **1,620개의 곡면 조각(5배)**으로 재구성됩니다. 사각형 대신 양끝이 가늘어지는 곡면 렌즈/리본을 사용하고, 넓은 나선 면과 중앙의 빛도 면으로 채웁니다. 완성 은하에는 점/원 테두리/와이어를 그리지 않습니다.
- 은하의 완성 배율은 1.5입니다. 커서의 좌우 위치에 따라 회전 방향이 바뀌고, 위아래 위치에 따라 기울기가 달라집니다. 반응은 부드럽게 따라가며 커서가 장면을 벗어나면 기본 각도로 돌아옵니다. 실제 도시/천문 데이터가 아닌 추상 그래픽입니다.
- 터치는 기존 네이티브 스크롤을 유지합니다. 모션 감소에서는 커서 반응과 자동 동작을 멈춥니다. 숨은 탭·화면 밖·모달 정지와 라우트 이탈 시 프레임/관찰자/포인터 이벤트 정리를 유지합니다.
- 실행 코드는 단일 `index.html`이며 기존 CMS·설정·데이터·Vercel rewrite·브랜드 가이드·서버 정책은 보존합니다.

## 스크롤 등장과 진행 유지

- 사용자가 요청한 상품 소개 페이지처럼, ABOUT 소개 제목·본문·설명·People/문의 소개가 스크롤에 따라 단어 순서대로 투명도 0.12→1로 선명해집니다. 텍스트 위치를 움직이지 않으며, 공백/줄바꿈/서체/의미 구조와 기존 큰 제목의 알파벳 전환을 유지합니다. 기본 문서는 전체 텍스트를 제공하고 JavaScript가 없으면 모두 선명하게 표시합니다.
- 각 문구는 도달한 가장 높은 밝기를 보존합니다. 위로 스크롤해도 다시 흐려지거나 숨지 않습니다. 완료된 문구는 추가 스타일 갱신을 중단합니다. 모션 감소에서는 처음부터 전체 문구를 선명하게 제공합니다.
- 첫 X의 결집과 두 번째/세 번째 장면의 스크롤 진행도도 최고 도달치를 보존합니다. 처음 내려갈 때 순서대로 완성되지만 역스크롤하면 역재생하지 않습니다. 같은 ABOUT 방문 동안 유지하며 다른 라우트로 나갔다가 다시 들어오거나 새로고침하면 새 소개로 시작합니다.
- 완성 뒤의 점/선/은하 자동 움직임과 마우스 반응은 유지합니다. 화면 밖의 Canvas는 스크롤에 의한 불필요한 재그리기를 중단합니다. 글자 등장에 쓰는 스크롤/크기/탭/모션 설정 이벤트도 라우트 이탈 시 정리합니다.
- `tests/about-motion-refinements.cjs`에 1440/390/320px의 단계별 단어 밝기/부분 등장/완료/역스크롤 밝기 유지와 두 장면의 진행 유지 검증을 추가했습니다. `tests/about-cinematic.cjs`는 첫 X 결집의 역재생 방지를 확인합니다. `tests/feed-people-scenes.cjs`도 누적 진행 기준으로 갱신했습니다. 앞선 역스크롤 재생 검증은 이 사용자 지시로 대체합니다.
- 최신 소스에서 문구/누적 진행/기존 시각 조정의 3개 폭 검증, 기존 ABOUT·문의/FEED·구성원 검증, 5개 폭×10개 라우트 회귀를 실행해 모두 통과했습니다. 브라우저 오류 0개이며, 단계별 투명도 화면도 직접 검토했습니다. 구성 객체·브랜드 가이드·Vercel 경로·서버 정책과 운영 데이터는 보존했습니다.

## 사각 파티클과 국소 상호작용

추가 사용자 요청에 따른 변경입니다.

- `POSSIBILITIES BY X`의 대체 글자 갱신 간격은 유지하고, 대체 상태 유지/순차 정착 시간을 이전의 70%로 줄였습니다. 총 전환은 약 3.4초→2.4초이며 대체 횟수도 약 70%입니다. 글자의 자연 비례·행 전체 맞춤·최종 제목·모션 감소 대응은 유지합니다.
- 은하는 **3,888개 사각 면**으로 구성하며, **2,268개를 중심의 타원체 부피**에 배치했습니다. 나머지는 나선 팔을 이룹니다. 이전 곡면 리본·반투명 원반·중앙 광원 그림은 모두 제거했으며 완성 은하는 사각 면만 그립니다.
- 각 면은 실제 3차원 위치/기울기/높이를 갖고, 원근 투영과 깊이순 그리기/명암으로 앞뒤를 구분합니다. 위치와 각도가 시간에 따라 조금씩 흔들리므로 고정된 판처럼 보이지 않습니다. 완성 확대율은 1.5→1.85입니다. 외곽 일부가 화면 가장자리를 넘어가는 확대 장면이며 페이지 가로 넘침은 발생하지 않습니다.
- 은하를 클릭하면 60도 회전하고 마우스 버튼을 누른 채 드래그하면 회전/기울기를 조절합니다. 방향키·Enter/Space·Escape(초기화)도 지원합니다. 클릭/드래그로 정한 각도는 커서가 떠나도 유지합니다. 기존 커서 위치에 따른 부드러운 반응과 자동 움직임도 보존합니다.
- 경험 장면이 완성되면 커서 가까운 선만 밝아지고 이동 잔상의 굵기/밝기/속도가 변합니다. 이동 위상은 프레임마다 누적하므로 커서 이동에 따라 선이 순간 이동하지 않습니다. 커서가 떠나면 기본 밝기와 속도로 부드럽게 돌아옵니다.
- 문구의 한번만 등장하는 투명도, 세 장면의 최고 진행도 유지, 100svh 검은 간격, 단일 HTML/기존 CMS/설정/라우트/브랜드 가이드를 보존합니다. 모션 감소·모달/숨은 탭 정지·이탈 시 포인터/클릭/키보드 이벤트 정리와 네이티브 터치 스크롤도 유지합니다.

검증은 `tests/about-motion-refinements.cjs`에서 1440/390/320px의 제목 정착 시간·사각 면 3,888개·중심 개수/깊이·곡면/원/그라디언트/배경 이미지 없음·확대·실제 클릭/드래그/키보드 회전·경험 근접 조명/속도와 복귀를 확인했습니다. 기존 문구/진행 유지·검은 간격·모달/모션 감소·넘침도 통과했습니다. 5개 폭×10개 라우트와 기존 ABOUT/문의·FEED/구성원 검증도 통과했고 브라우저 오류는 0개입니다. 최신 데스크톱/모바일 이미지를 직접 검토했습니다. 이 PC의 헤드리스 Chrome 1초 표본에서 완성 은하가 1440px 21프레임, 390px 23프레임을 갱신했으며 실제 휴대전화 성능을 보장하는 측정은 아닙니다. 관련 결과와 이미지는 `tests/artifacts/`에 갱신했습니다. 실제 기기/Safari/Firefox/스크린리더와 운영 쓰기는 여전히 미검증입니다.
