## 확정된 화면

- 헤더/메뉴: 현재 승인된 굴절 유리 알약, 빠른 이동, 배경에 따른 대비. 슬롯은 우측 정렬하며 밝은 배경의 검정 박스/흰 글자, 어두운 배경의 흰 박스/검정 글자입니다.
- WORKS: 떠 있는 유리 보기 전환/필터, 아이콘과 X가 같은 자리에서 변형되는 고정 필터, 카드 간격, 원형 TOP. 정렬은 필터 안에서 항상 보입니다.
- 프로젝트: 흰 이미지 여백, 투명 제목 배경, 내부 세로 스크롤 제거. Cover Flow는 실제 처음과 끝이 있고 PC에서 앞뒤 3장씩 최대 7장, 모바일은 선택 사진을 크게 하고 가까운 앞뒤 사진을 눕힙니다. 스와이프를 지원하며 화살표·개수 표시·하단 프로젝트 Prev/Next는 제거했습니다.
- ABOUT: 중앙의 두 줄 POSSIBILITIES/BY X. 흰 박스와 BY/X의 크기·위치는 글자 교체 중 고정합니다. 첫 화면의 소개 문구는 숨기고 스크롤 후 공개합니다. 장면 상하 감쇠, 문서와 함께 지나가는 거의 검정인 안개 배경, 형상을 유지하는 경험의 국소 선 반응과 넓게 흩어지는 은하 전환을 사용합니다.
- People: 좌우 드래그/스와이프, 둥근 유리 프로필. 불필요한 제목과 구분선을 제거했습니다.
- Dream with us: ABOUT은 흰색, CONTACT는 검정. 호버 시 위치·크기를 유지하며 색/그림자만 서서히 바뀝니다. 버튼에서 둥근 문의창으로 확장합니다.
- CONTACT: Visit 설명 제거, PC 한 화면, 왼쪽 아래 Dream 버튼. 푸터 사업자 정보는 중앙 정렬입니다.
- 모바일 기울기: 켜기/끄기 버튼은 제거했습니다. 지원 기기는 자동 연결, 권한 요청이 필요한 기기는 본문 직접 터치에서 요청합니다. 실제 휴대전화 검증은 사용자 확인 예정입니다.

## 편집과 관리자 계정

- 일반 메뉴에 로그인/관리자 링크를 노출하지 않습니다. `/admin`에서 로그인한 계정에만 허용된 편집 메뉴와 편집바가 나타납니다.
- 기존 관리자 1개는 Owner입니다. Accounts에서 계정 추가, Owner/Editor 지정, Project/Feed/About/Contact/Inquiries 권한을 설정합니다.
- 새 계정은 임시 비밀번호로 로그인하고 첫 비밀번호 변경 후 편집합니다. 자동 초대 이메일은 보내지 않습니다.
- 접근 권한 제거는 즉시 CMS 접근을 차단하고 기존 신원·글·이미지는 보존합니다. 같은 이메일과 새 임시 비밀번호로 복구합니다. 본인/마지막 Owner 제거는 차단합니다.
- Feed는 하나의 시각 편집기입니다. 소제목/인용/목록/인라인 서식의 자동 변환, `?` 도움말, 정렬 아이콘, 색상·이미지 묶음과 기존 본문 블록 호환을 제공합니다.
- CATEGORY/프로젝트 유형/상태는 명시적 선택 메뉴와 직접 입력을 지원합니다. 문의함의 화면 명칭은 Inquiries입니다.
- 자세한 사용법·서버 정책·검증: [Feed와 계정 관리](CMS_ACCOUNTS_2026-11-06.md).
