# 회전 범위·국소 밀도·유리 메뉴·푸터 간섭 수정

2026-11-05 추가 사용자 요청입니다. [이전 모션 기록](MOTION_REFINEMENTS_2026-11-05.md)보다 이 문서의 회전 범위·입력·경험 조명·메뉴 전환 기준을 우선합니다.

## 변경

- 은하는 매 프레임 카메라 투영이 끝난 사각 면의 전체 경계를 구하고, 현재 Canvas 폭/높이 안에 여유를 두고 맞춥니다. 특정 각도에서 바깥 나선 팔이 잘리는 문제를 해결하면서 화면 안에서 가능한 큰 크기를 유지합니다. 5,832개 면·개별 투명도·입체 배치·클릭/드래그 회전은 유지합니다.
- 방향키 회전과 Escape 초기화 및 키 안내 문구를 제거했습니다. Enter/Space의 클릭 대응은 유지하고 접근성 설명에서 제거한 조작을 안내하지 않습니다.
- 경험은 완성 상태의 기본 선 밝기를 낮추고 커서 주변 선의 발광·두께를 더 크게 높입니다. 가까운 궤적에는 여러 평행 이동 선 조각을 추가해 실제 선 밀도가 높아집니다. 원형 조명 덧칠 없이 선 자체의 블러 발광을 사용합니다. 형상 전체도 커서에 따라 약하게 회전/기울어지고 커서가 떠나면 원래 각도·밝기·밀도로 돌아옵니다. 결집 전에는 기본 밝기를 더 유지해 배경의 움직임을 읽을 수 있게 했습니다.
- 데스크톱 메뉴는 여러 단계의 크기/위치 변경 대신 하나의 연속 스프링 곡선을 720ms 동안 재생합니다. 위치·늘어남·눌림을 **transform만으로** 합성하며 이동 중 매 프레임 레이아웃 측정과 문자색 반전을 제거했습니다. 반투명 바탕·14px 배경 블러·굴곡진 테두리 광택은 정착 후에도 유지합니다. 연속 선택은 현재 표시 위치에서 이어지며 모션 감소는 즉시 정착합니다. 투명도 감소 설정에서는 블러 없는 불투명 바탕을 사용합니다.
- WORKS의 맨 위 화살표는 기본 고정 위치를 유지하다 푸터가 들어오면 그 위로 올라갑니다. 짧은 목록과 스크롤 끝에서도 인스타그램 링크·사업자 정보와 겹치지 않으며 푸터 크기/창 크기 변경에도 위치를 갱신합니다.

## 파일·보존

실행 변경은 `index.html`입니다. 운영 연결 없는 `prototypes/visual-foundation/current.html`, 관련 검증 스크립트/화면과 기록을 동기화했습니다. `tests/scene-interaction-polish.cjs`를 추가했고 기존 모션/헤더/라우트 검증을 새 동작에 맞췄습니다.

단일 HTML·설정 객체·슬롯 로고·공개 라우트·FEED/People/CMS/문의·Vercel rewrite·서버·Auth/Storage·브랜드 가이드와 운영 데이터는 보존합니다. 운영 데이터 쓰기 검증은 수행하지 않았습니다.
