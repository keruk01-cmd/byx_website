# BYX — 현재 미리보기와 이전 비교 시안

현재 기능 개선의 격리 데모는 **[current.html](current.html)** 입니다. 푸터·배치 로딩·프로젝트 지도/날짜/기간/상태·ABOUT·FEED를 기존 사이트 코드에서 확인할 수 있습니다. 로컬 서버에서는 `http://127.0.0.1:8742/current.html`로 엽니다. 운영 연결이 없으며 관리자 저장은 메모리 데모입니다. 아래 A/B는 이전 시각 비교 기록입니다. 현재 변경 내역은 [기능 개선 기록](../../docs/SITE_UPDATES_2026-11-03.md)을 따릅니다.

최종 정리일: 2026-11-03. 현재 구현은 가로로 꽉 찬 X 점군 영역·흰 제목·4.8초 형상 전환·강화된 호버/클릭, 유리 헤더, 최신 큰 카드와 작은 아카이브형 FEED를 포함합니다. 실제 구현 소스 `index.html`은 로컬 수정했고, `current.html`은 그 소스에서 운영 설정과 외부 Supabase SDK를 제거한 사본입니다. 운영 DB·배포는 변경하지 않았습니다.

## 현재 미리보기 실행

`current.html`을 직접 열거나 저장소 루트에서 다음 명령을 실행합니다.

```powershell
node prototypes/visual-foundation/preview.cjs
```

- WORKS: `http://127.0.0.1:8742/current.html#/`
- ABOUT: `http://127.0.0.1:8742/current.html#/about`
- FEED: `http://127.0.0.1:8742/current.html#/feed`
- 종료: `Ctrl+C`. 기본 `/`는 이전 A 시안을 열기 때문에 `current.html` 주소로 들어갑니다.

사진·지도처럼 외부 자료를 사용하는 기능에는 인터넷 연결이 필요할 수 있습니다. 지도 타일은 HTTP에서만 요청합니다. 현재 검증은 [tests/site-regression.cjs](../../tests/site-regression.cjs)와 [결과 JSON](../../tests/artifacts/results.json)에 기록되어 있습니다. 아래 `verify.cjs`의 검증과 A/B 수치·메뉴는 과거 비교 시안에만 해당합니다.

## 먼저 볼 화면 — 이전 A/B 비교 기록

이 아래는 2차 비교 시안을 만들었을 당시의 기록입니다. ‘운영 파일을 수정하지 않았다’는 설명도 당시 A/B 제작 범위에만 해당합니다. 현재 작업의 완료·미검증 상태는 상단의 작업 정리를 기준으로 합니다.

**[A · 기본 개선](a.html)을 기준안으로 봅니다.** 상단의 ‘기존 화면’으로 이동하면 같은 페이지의 개선 전 상태와 비교할 수 있습니다. [B · X 추가 검토](b.html)는 A와 같은 화면에서 사진 없는 프로젝트 썸네일만 X 그래픽으로 바꾼 선택 실험입니다. 서로 다른 두 사이트를 선택하는 방식으로 진행하지 않습니다.

모든 HTML은 파일 탐색기에서 더블클릭해 열 수 있습니다. 설치·빌드·인터넷 연결이 필요 없습니다. 선택 사항인 로컬 서버는 저장소 루트에서 다음처럼 실행합니다.

```powershell
node prototypes/visual-foundation/preview.cjs
```

- [기존 화면](http://127.0.0.1:8742/original.html)
- [A · 기본 개선](http://127.0.0.1:8742/a.html)
- [B · X 추가 검토](http://127.0.0.1:8742/b.html)
- 종료: `Ctrl+C`. 서버는 프로토타입 폴더만 제공합니다.

## 피드백과 이번 수정

| 사용자 피드백 | 반영 |
|---|---|
| Anton이 더 나음 | 영문 제목·메뉴·슬롯 모두 기존 Anton 유지. Gasoek One·Archivo Black 교체 실험을 중단 |
| PC 그리드가 너무 큼 | 1440px에서 4열·카드 360px, 1920px에서 5열·카드 384px |

| WORKS·STUDIO만 남은 메뉴가 낯섦 | 기존 WORKS·NEWS·BLOG·ABOUT·CONTACT 및 모바일 메뉴 복원 |
| 기존 사이트를 버린 느낌 | 운영 `index.html`의 문자열 뷰·라우터·갤러리·슬롯·데모 CMS를 그대로 가져온 사본에서 필요한 CSS만 조정 |
| A/B 차이가 불명확함 | A는 기본 개선, B는 사진 없는 카드의 X 그래픽이라는 한 가지 추가 차이로 한정 |

전 단계에서 메뉴를 임의로 축소하고 별도 소개 영역을 추가했던 방향을 철회했습니다. 이번에는 기존 홈처럼 헤더와 GRID/INDEX 아래에서 작품이 바로 시작합니다. 별도 STUDIO 섹션·샘플 상세 모달도 사용하지 않으며, 원래 프로젝트 상세·NEWS·BLOG·ABOUT·CONTACT 페이지로 이동합니다.

## A에서 바뀌는 범위

| 요소 | 기존 사이트의 격리 사본 | A 기본 개선 |
|---|---|---|
| 1440px 카드 밀도 | 3열, 약 479px | 4열, 360px |
| 1920px 카드 밀도 | 기존 반응형 규칙 | 5열, 384px |
| 모바일 390·320px | 1열 | 1열 유지 |
| 이미지/설명 순서 | 이미지 → 작품명·코드·메타정보 | 순서·이미지 4:3 비율 유지 |
| 1440px 작품명 | Anton 30px | Anton 약 23.76px |
| 본문·메타정보 | SUIT Variable | 기존 브랜드 방향의 Wanted Sans, 기존 폴백 보존 |
| 카드 여백 | 기존 캡션 여백 | 상하 여백과 메타정보 간격을 소폭 정리 |
| 로고·메뉴·페이지 구조 | 기존 구조 | 유지 |

그리드 최소 카드 폭은 330px입니다. 넓이에 따라 열 수가 늘어나고, 880px 이하에서는 기존 240px 기준 반응형 규칙, 520px 이하에서는 기존 1열 구조를 따릅니다. 카드에 흰 바탕을 유지해 마지막 행의 빈 트랙이 검은 판으로 보이지 않게 했습니다.

Anton은 이번 개선안의 기준 서체입니다. 더 두꺼운 서체로 교체하는 결정을 추가로 요구하지 않습니다. Wanted Sans 적용 범위는 본문·메타정보이며 슬롯 서체·폭·밑줄·착시 보정값은 건드리지 않습니다.

## B의 추가 실험

B는 A의 메뉴·레이아웃·카드 크기·텍스트를 그대로 사용합니다. **사진이 없는 프로젝트의 `artOf()` 폴백에만** 결정론적 X 스터디를 적용합니다. 사진 URL이 있으면 기존 이미지를 그대로 표시합니다. NEWS·BLOG·PEOPLE·지도·프로젝트 상세의 생성 그래픽은 기존 방식을 유지합니다.

X의 두께·비율은 프로젝트 코드에 따라 정해지며, 같은 코드에는 같은 그림이 나옵니다. 썸네일 내부의 비조작 그래픽이므로 별도 닫기 버튼처럼 배치하지 않습니다. 새로운 자동 모션은 없습니다. 이 그래픽은 선택 검토 사항이며 기본 개선에 반드시 포함할 요소가 아닙니다.

## 원본 보존과 데모 격리

- 세 화면은 운영 `index.html`에서 생성한 독립 사본입니다. 원본 파일과 `vercel.json`을 변경하지 않았습니다.
- 사본의 `window.BYX_CONFIG` 값은 비웠고 외부 Supabase SDK 로드를 제거했습니다. 운영 키·주소·데이터는 복사하지 않았습니다. DB·로그인·업로드는 기존 메모리 데모 경로로만 작동합니다.
- CSP의 `connect-src 'none'`으로 외부 API 연결을 차단합니다. CONTACT는 외부 지도 iframe 대신 기존의 생성 약도 폴백을 사용합니다. 지도 기능의 변경·배포를 의미하지 않습니다.
- 관리자에서 변경한 데모 데이터는 새로고침하면 초기화됩니다. 운영 데이터·Auth·Storage·Vercel 설정은 변경하지 않습니다.
- 슬롯의 회전·연장·고정 밑줄·긴 단어 맞춤·착지 안전망과 갤러리·편집기 등 기존 코드 경로를 유지합니다. 모션 감소를 실행 중 켰을 때의 정리도 격리 사본에만 포함했습니다.
- 상단 비교 링크는 현재 해시를 다음 사본에도 전달합니다. 예를 들어 NEWS를 보다가 ‘기존 화면’을 누르면 NEWS로 비교합니다.
- 프레임워크·npm 의존성·빌드 단계를 추가하지 않았고, 커밋·푸시·배포하지 않았습니다.

기존 문서: [개발 기준](../../AGENTS.md), [브랜드 기준](../../docs/BYX_BRAND.md), [구현 계획](../../docs/BRAND_IMPLEMENTATION_PLAN.md). 이번 ‘Anton 유지·기존 사이트 개선’ 지시를 과거 서체 탐색안보다 우선 적용했습니다. 기존 문서의 미결 항목을 운영 교체 승인으로 해석하지 않습니다.

## 검증과 기록

이번 2차 검증은 [qa/revision-2/results.json](qa/revision-2/results.json)에 있습니다. 이전 `qa/` 바로 아래 캡처와 결과는 1차 시안의 과거 기록입니다.

- 설치된 Chrome + 기존 Playwright로 기존 화면·A·B의 11개 화면 조합을 확인했습니다. 기존 화면은 1440·390·320px, A/B는 1920·1440·390·320px입니다.
- 각 조합에서 9개 기존 라우트의 해당 화면 렌더와 가로 넘침을 확인했습니다.
- 데스크톱 4열/5열·카드 실측 폭, Anton 유지, 모바일 1열과 다섯 메뉴를 확인했습니다.
- A/B에서 데모 로그인 → 프로젝트 이름 입력 → 포커스 유지 → 메모리 저장 → 새로고침 초기화를 확인했습니다. 운영 저장 검증이 아닙니다.
- GRID/INDEX·연월 정렬·슬롯 연장·밑줄 고정·정상 착지·모션 감소·모바일 메뉴 이동·직접 HTML 열기를 확인했습니다.
- B의 동일 코드/동일 X 결과와 사진 URL 우선 사용을 확인했습니다.
- 브라우저 실행 오류 0건, 외부 요청 0건입니다.
- [기존 1440](qa/revision-2/original-1440.png), [A 1440](qa/revision-2/a-1440.png), [A 390](qa/revision-2/a-390.png), [B 1440](qa/revision-2/b-1440.png) 캡처를 남겼습니다.

미검증: 실제 휴대전화, Safari/Firefox, 스크린리더, 운영 CMS 쓰기, 운영 이미지·콘텐츠, 외부 지도, Vercel 대시보드. 이번 데모 결과로 운영 기능 전체가 재검증되었다고 보고하지 않습니다. 이미지 업로드·갤러리의 전체 조작 검증도 이번에는 재수행하지 않았습니다.

## 파일

`original.html`, `a.html`, `b.html`은 각각 독립 실행 파일입니다. `preview.cjs`는 선택 사항인 로컬 서버, `verify.cjs`는 QA 도구입니다. `licenses/`에는 폰트 출처와 고지가 있습니다. 사본에 사용한 폰트는 원래 내장 Anton·SUIT와 이전 시안에서 가져온 Wanted Sans이며 새 네트워크 다운로드는 수행하지 않았습니다.
